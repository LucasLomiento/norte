- **Hidden sidebar without the strip at the edge:** with the window frame set to 0 (or below 3), the hidden sidebar left a dark 3 px strip at the left edge of the page. Now the page goes all the way to the edge, and touching it with the pointer still brings the sidebar back. With the frame above 3, hiding and showing the sidebar (Ctrl+S) no longer makes the page bounce back a few pixels at the end of hiding and the start of showing.
