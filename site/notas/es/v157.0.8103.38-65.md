- **Chromium 157.** Norte pasa de Chromium 155 a 157.0.8103.38, con las correcciones de seguridad de ambas versiones.
- **Versiones firmadas.** Los paquetes y la base de datos de pacman ahora van firmados con una clave GPG. Si instalaste antes de esto y tu `pacman.conf` tiene `SigLevel = Optional TrustAll`, pacman pregunta una vez si puede importar la clave: responde que sí y todo sigue funcionando. Para la verificación completa, sigue el [README](https://github.com/LucasLomiento/norte-releases#readme).
- **Más formas de instalar.** Un `.deb` para Debian 12+, Ubuntu 24.04+ y derivadas, que se actualiza desde el aviso al pie de la barra lateral, como el paquete de pacman.
- **Además:** las funciones de IA nuevas que trae Chromium 157 quedan desactivadas, y Norte ahora abre en sistemas sin journald, como contenedores y distrobox.
